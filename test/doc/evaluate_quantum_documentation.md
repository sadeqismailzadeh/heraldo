# Documentation for `evaluate_quantum.py`

## 1. Overview

This script is designed for the **qualitative analysis** of a trained reinforcement learning agent. Its purpose is to load a saved model, run it in the quantum circuit environment for a few episodes, and provide a detailed, step-by-step visualization of its behavior.

This is in contrast to `article_fig3.py`, which performs quantitative analysis over many episodes. This script is for observing *how* the agent achieves its results in a single episode.

## 2. Core Functionality

The script performs the following actions in a loop for a specified number of episodes (`num_episodes`):

1.  **Load Model and Environment**: It initializes a single instance of the `QuantumCircuitEnv` (with parameters matching those used during training) and loads the final trained PPO model from the `ppo_quantum_circuit.zip` file.
2.  **Run an Episode**: It resets the environment and then enters a `while` loop that continues until the episode is terminated or truncated.
3.  **Predict Actions**: In each step of the loop, it uses `model.predict(obs, deterministic=True)`.
    -   `deterministic=True` is important for evaluation. It makes the agent choose the action with the highest probability from its learned policy, rather than sampling from the policy's probability distribution (which is done during training to encourage exploration). This shows the agent's "best" learned strategy.
4.  **Log Step-by-Step Information**: After each step, it prints a detailed log to the console, including:
    -   The current step number.
    -   The precise action taken by the agent (e.g., the transmissivity `tau_1` and `squeezing_phase`).
    -   The number of photons measured in that step (`Measured_n`).
    -   The reward received for that step.
5.  **Post-Episode Analysis**: Once an episode finishes, it prints a summary:
    -   Total steps taken.
    -   Total reward accumulated.
    -   The final fidelities calculated against all four target states.
    -   The best (maximum) fidelity achieved and which target state it corresponds to.
6.  **Visualize the Final State**: This is the most critical output of the script.
    -   It retrieves the final quantum state from the environment.
    -   It calculates the **Wigner function** of this state. The Wigner function is a quasi-probability distribution that provides a powerful phase-space representation of a quantum state. For GKP/cat states, it has a very distinct and recognizable pattern.
    -   It uses `matplotlib` to generate a 2D contour plot of the Wigner function, providing an intuitive visual confirmation of how well the agent succeeded in creating the target state. The plot is titled with the best fidelity achieved in that episode.

## 3. How to Use

1.  Ensure that a trained model file named `ppo_quantum_circuit.zip` exists in the same directory. This file is generated by `train_quantum_circuit.py`.
2.  Run the script: `python evaluate_quantum.py`.
3.  Observe the console output for step-by-step details of each episode.
4.  A `matplotlib` window will appear after each episode, showing the Wigner function of the final state. Close the plot window to proceed to the next evaluation episode.

## 4. Flowchart of Script Execution

```mermaid
graph TD
    A[Start Script] --> B[Load Trained PPO Model];
    B --> C[Initialize QuantumCircuitEnv];
    C --> D[Start Episode Loop (for num_episodes)];
    D --> E[Reset Environment];
    E --> F[Start Step Loop (while not done)];
    F --> G[Get Observation from Env];
    G --> H[model.predict(obs, deterministic=True)];
    H --> I[Get Action];
    I --> J[env.step(Action)];
    J --> K[Receive new (obs, reward, done, info)];
    K --> L[Print Step Details to Console];
    L --> F;
    F -- Episode Done --> M[Episode Finished];
    M --> N[Print Episode Summary (Total Reward, Best Fidelity)];
    N --> O[Get Final Quantum State from Env];
    O --> P[Calculate Wigner Function of the State];
    P --> Q[Plot Wigner Function using Matplotlib];
    Q --> R{More episodes to run?};
    R -- Yes --> E;
    R -- No --> S[End Script];
```
