# Installation

## Prerequisites

- Python 3.9 or higher
- Strawberry Fields
- SymPy, SciPy, NumPy, Numba, Pandas

## Installing `heraldo`

Clone the repository and install in editable mode:

```bash
git clone https://github.com/your-repo/heraldo.git
cd heraldo
pip install -e .
```

To build the documentation locally, install documentation dependencies:

```bash
pip install -r docs/requirements.txt
```
